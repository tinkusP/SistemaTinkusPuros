AUDITORÍA DEL ERROR 404 — REPORTE INTEGRANTES POR MATRÍCULA
Fecha: 11 de septiembre de 2026

ERROR OBSERVADO
================
El botón DESCARGAR EXCEL termina mostrando HTTP 404. Se reprodujo contra el backend público configurado en Railway: GET /api/reportes/integrantes-matricula respondió 404 con "Cannot GET /api/reportes/integrantes-matricula".

REQUEST FRONTEND
================
Método: GET.
Ruta relativa: /reportes/integrantes-matricula.
Parámetros actuales: ninguno por defecto; el componente aplica los filtros de bloque y sexo en memoria después de obtener el reporte.
Cliente: instancia Axios de frontend/src/lib/axios.ts.
Base URL esperada: VITE_API_URL debe apuntar al backend Railway y terminar en /api. No se reproduce aquí ningún valor privado.
URL efectiva esperada: [backend Railway]/api/reportes/integrantes-matricula.
No existe /api duplicado: la base aporta /api y ReporteApi aporta /reportes/...

RUTA BACKEND ESPERADA Y LOCAL
=============================
Ruta del router: GET /integrantes-matricula en backend/src/routes/ReporteRoutes.ts.
Montaje: app.use("/api/reportes", reporteRoutes) en backend/src/server.ts.
Ruta completa local: GET /api/reportes/integrantes-matricula.
Protección: authenticate + soloAdministradorReal.
Controlador: reporteIntegrantesPorMatricula.
Servicio: obtenerReporteIntegrantesBloque.

RUTA BACKEND DESPLEGADA
=======================
La comprobación HTTP de solo lectura al dominio público devolvió 404 y no 401. Esto demuestra que la aplicación Railway que respondió no contiene la ruta. Si la ruta estuviera desplegada, una solicitud sin token llegaría a authenticate y respondería 401, no "Cannot GET".

CAUSA RAÍZ
==========
No hay diferencia de singular/plural, método o prefijo entre el frontend y el código backend local. La causa comprobada es una diferencia de versión entre servicios: el frontend ya solicita el endpoint nuevo, mientras el backend activo de Railway continúa ejecutando una compilación anterior que no lo incluye. El código local y origin/main contienen el endpoint y su montaje, pero el despliegue público observado está desactualizado.
