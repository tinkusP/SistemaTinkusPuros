# SistemaTinkusPuros

Sistema web de administración de la Fraternidad Tinkus Puros y Naturales.

## Estructura

- `frontend`: React, TypeScript y Vite.
- `backend`: Node.js, Express, TypeScript y MongoDB.

## Desarrollo local

Configura `backend/.env` y `frontend/.env` a partir de sus respectivos archivos `.env.example`.

```bash
cd backend
npm install
npm run dev
```

```bash
cd frontend
npm install
npm run dev
```
